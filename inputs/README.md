# Synthetic Sample Inputs (`inputs/`)

All sample documents included in this folder (`testdocs.parquet` and `testdocs/doc1.txt`–`doc5.txt`) are **100% synthetic, fictional mock clinical evaluation reports** generated exclusively for testing and demonstrating the SemanticPrism pipeline.

* **Zero Real Patient Data / Zero PHI:** Names, organizations, clinical histories, psychometric scores, and calendar dates in these sample files are entirely fictional and do not correspond to any real individual, patient, or clinical encounter.
